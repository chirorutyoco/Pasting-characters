# いあきゃら・キャラッシュ → ココフォリア

いあきゃら・キャラッシュのキャラを、アイコン・立ち絵つきのコマとしてココフォリアに作る Chrome 拡張です。無料・ボタン2回で完了します。

**対応**: いあきゃら(CoC 6版・7版)/ キャラッシュ(エモクロア・ガイアケア・10_st・CoC 6版・7版)
※キャラッシュの「オリジナル」は駒出力が無いため対象外です。

## インストール(初回のみ)
1. [Releases](../../releases/latest) から `ia-ccfolia-ext_v*.zip` をダウンロードし、消えない場所に展開する(使い続ける間は削除・移動しない)。
2. Chrome で `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダ(`manifest.json` がある場所)を選ぶ。

更新するときは、古い拡張を削除してから、新しい zip で同じ手順を行います。

## 使い方
1. **保存**: キャラのページ(`view` / `edit`)でツールバーのボタンを押す。「○○ を保存しました」と出れば完了。続けて何人でも保存できます。
2. **コマを作る**: ココフォリアのルームでボタンを押す。保存した全員が、保存順にコマになります(作成中は再度押さない)。

キャラの一覧ページでは保存できません。1人ずつのページで押してください。

## 便利機能
- **お気に入り**: ボタンを右クリックで登録・追加・削除(期限なし)。
- **ココフォリアのコマを別ルームへ**: コマを左クリックして選びボタンを押すと保存。別のルームで何も選ばずに押すと作れます。
- 保存したキャラは3時間で消え、作成できたキャラも消えます。

## 補足
- 画像が2枚以上のキャラは、全画像が立ち絵になります。
- いあきゃらは HP・MP の現在値欄が無いため、最大値と同じ値で作られます。

## うまくいかないとき
- 「ページを再読み込み(F5)してから…」と出たら、F5 を押してやり直す。
- 「保存済みのキャラがありません」と出たら、先にキャラのページで保存する。
- サイトの仕様が変わると動かなくなることがあります。

## プライバシー
キャラのデータと画像はブラウザ内にだけ保存し、外部サーバーには送りません。通信は各サイトからの取得と、ココフォリアへのアップロードだけです。ログイン情報・Cookie には触れません。

非公式の拡張です。いあきゃら・キャラッシュ・ココフォリアとは関係ありません。利用は自己責任でお願いします。
